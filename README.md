# Power BI Netflix Data Analysis

## Project Overview

This project demonstrates an end-to-end data analysis workflow using **Power BI** and Netflix titles data.

The analysis focuses on data cleaning, transformation, data modeling, mapping tables, exploratory analysis, and dashboard reporting to identify meaningful trends and insights from the dataset.

## Objectives

- Clean and transform raw Netflix titles data
- Prepare data for analysis using Power Query
- Create mapping tables to improve data organization
- Analyze Netflix content by type, country, genre, rating, and release year
- Build interactive Power BI reports and visualizations
- Identify patterns and trends that can support business-style decision making

## Tools & Technologies

- **Power BI**
- **Power Query**
- **DAX**
- **Data Modeling**
- **Excel / CSV Data**
- **GitHub**
